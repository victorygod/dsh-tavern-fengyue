# Engineering Notes / 工程笔记

`docs/notes/` 是开发期的定案与修复笔记（功能定案、bug 修复、测试基建），按 `YYYY-MM-DD-*.md` 命名。每篇 `*.md` / `*.zh.md` 双语成对，`*.i18n.yaml` 是翻译管线元数据。

These dated decision/bug-fix notes are a historical record of how this project was built. They are not maintained docs: on any conflict, the code and the READMEs win. Long-lived user-facing documentation lives one level up in [`docs/`](..) — see "Docs" in the project README.
