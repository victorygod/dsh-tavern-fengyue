# DND5e 规则汇编（卡设计的规则底稿）

本文档是「原味 5e」卡设计的规则素材：把 D&D 5e 的规则骨架完整整理成可逐条讨论的条目，供下一步归类到引擎四宿主——**脚本**（规则执行器）/ **lore**（有界固定清单）/ **面板**（可变状态）/ **提示词**（裁量与纪律）。本稿只整理规则，不做归类结论；文末的归类初判是 v0 草案，供分析推翻或确认。

口径与约定：

- **基线 = 2014 版 PHB/DMG（SRD 5.1）的数学骨架**——5e 简中社区知识的主脉络。2024 复审版差异收在附录，不进基线。
- 只收录**规则数学与有界清单**，不复述专长/子职业/法术单卡散料（卡设计时按需从 SRD 取）。
- 「有界」= 枚举封闭、逐条语义明确（技能/状态/伤害类型/武器护甲/法术位表…）；「无界」= 数值连续或含裁定（DC 数值、叙事时机）。
- **核检状态（2026-09-17 联网对源）**：数值大表与规则文本已对 Roll20 Compendium（SRD 原文镜像）、5thsrd.org、rpg.stackexchange 等源交叉核验；核验修正了本稿若干处（法师 9 级 5 环位、长休 HD 恢复口径、2024 短休时长、若干状态语义、护甲表）。未核区：各职业子类与专长散料（设计时按需自取 SRD）。

## 1 核心判定机制（d20 系统）

一切不确定判定统一为一个公式：**d20 + 修正值 ≥ 阈值**。三类判定：

| 判定类 | 阈值 | 修正值构成 |
|---|---|---|
| 属性检定 | DC（DM 设定） | 属性调整值 +（若熟练该技能）熟练加值 + 其它 |
| 攻击检定 | 目标 AC | 属性调整值 +（若熟练该武器）熟练加值 + 魔法加值等 |
| 豁免检定 | 效果 DC | 属性调整值 +（若该豁免熟练）熟练加值 |

伴生铁则：

- **熟练加值（Proficiency Bonus）**随总角色等级走：LV1–4 `+2` / LV5–8 `+3` / LV9–12 `+4` / LV13–16 `+5` / LV17–20 `+6`。只出现在「有资格熟练的事物」上，从不因难度加码。
- **优势/劣势**：掷 **2 个 d20 取高/取低**，修正值只加一次。多条优势不叠加，优势+劣势抵消为平掷——只问有没有，不问几个。这是 5e 数控的核心：用掷骰方式而非修正值堆叠表达形势。
- **取整一律向下**。
- **nat 20 / nat 1（2014）**：只有**攻击检定**有硬规则——nat20 必中且暴击、nat1 必失。属性检定与豁免无自动成败（2024 变体见附录）。骰值平手无法定规则（罕见，DM 裁定或重掷）。
- **掷骰前提**：不确定 + 成败皆有后果才掷；必成、必败、无代价的推进直接叙述。
- **被动检定**：`10 + 修正值`（优势 +5 / 劣势 −5），主用于醒觉；被动醒觉是「是否被伏击」的法定判据（对潜伏方的隐匿结果）。
- **合作与帮助**：帮助动作给同伴一次优势（任务须是帮助确实有用的才允许）；群体检定过半成功即整体过。
- 互动动作（拔剑/拉门/取物）每回合一次、不掷骰；只有失败有戏时才升级为检定。

## 2 六属性与豁免

| 属性 | 管辖 |
|---|---|
| 力量 STR | 近战（非灵巧）、擒抱推撞、负荷、跳跃距离 |
| 敏捷 DEX | 先攻、闪避（AC 贡献）、远程、灵巧武器 |
| 体质 CON | 每级 HP、专注豁免 |
| 智力 INT | 知识类技能、法师施法 |
| 感知 WIS | 洞察/察觉、牧师/德鲁伊施法 |
| 魅力 CHA | 交际诸技能、术士/契术师/诗人施法 |

- 调整值统一 `⌊(属性值−10)/2⌋`；凡人域 1–20（魔法物品可至 30）。
- 每个职业固定熟练**两项豁免**（有界清单，见 §12 G）。
- 效果豁免 DC 统一来源：`8 + 施法者熟练加值 + 施法者属性调整值`。

## 3 技能（18 项，有界）

| 属性 | 技能 |
|---|---|
| STR | 运动（跳/爬/游/擒/摔） |
| DEX | 杂技、巧手、隐匿 |
| INT | 奥秘、历史、调查、自然、宗教 |
| WIS | 驭兽、洞悉、医药、察觉、求生 |
| CHA | 欺瞒、威吓、表演、说服 |

- 不熟练的技能照检（只是不加熟练加值）；DM 可指定跨属性组合（如 STR(威吓)）。
- 盗贼/诗人可对选定技能**专精**（熟练加值翻倍）。

## 4 视野、隐匿与掩护

- **看不见的攻击者打你 = 它有优势**；**你攻击看不见的目标 = 你有劣势**。隐匿成功 → 视为不可见 → 下一击优势——「视觉优势」是最强的优势来源。
- **隐匿**：不可被看清才可尝试（重度遮蔽/全遮蔽典型）；隐匿 DEX 检定对抗每个敌人的察觉（被动醒觉优先）；攻击或施法立即暴露。
- **掩护**（对攻击与 DEX 豁免有效）：半掩护 `+2` AC、四分之三 `+5`、全掩护不可被直接指定目标（范围效果可波及）。

## 5 战斗秩序与行动经济

- **先攻**：各掷 `d20 + DEX 调整值`，高者先动，逐轮循环。平手 RAW = 同时行动（常见房规点）。
- **突袭**：对战双方的醒觉方用被动醒觉对抗潜伏方的隐匿。被突袭者本人在自己**第一个回合**不能移动与动作，且在该回合结束前不能反应。
- **每人每轮**：移动 + 1 动作（Action）+ 至多 1 附赠动作（须有特征触发）+ 至多 1 反应（非本人回合触发）。
- 动作枚举：攻击、施法、疾走（Dash，移动翻倍）、撤离（Disengage，本回合移动不触发借机）、闪避（Dodge，对看得见你的攻击者全劣势）、帮助、隐藏、搜索、预备（Ready，定条件+动作，触发用反应执行，专注保持到下轮开始或触发）、使用物品。额外攻击（Extra Attack）特征让攻击动作掷多次。
- **借机攻击**：敌人**自愿**离开你的触及范围时，可花反应做一次近战攻击（须能看见它）。被推离/坠/传送不触发。
- **双武器（2014）**：主手持轻武器攻击后，可用附赠动作以后手轻武器再攻击一次，后手伤害通常不加属性调整值。
- **擒抱/推撞（2014）**：替换一次攻击：`STR(运动)` 对目标的 `STR(运动)` 或 `DEX(杂技)`（目标择优）；胜则擒抱（速度 0，拖行半速）或推倒/推出 5 尺。
- **困境地形**移动加倍耗尺；倒地者爬行耗尺减半。
- 一轮战斗 = 6 秒（时间进位见 §15）。

## 6 攻击、AC 与伤害

- **攻击检定** `d20 + 属性调整值 + 熟练修正` vs AC。近战默认 STR、远程默认 DEX；**灵巧**武器可择 STR/DEX 之高者；投掷默认 STR（灵巧投掷武器择高）。
- **射程**：近战触及默认 5 尺（触及武器 10 尺）；远程武器射程 `X/Y`——超 X 打击劣势，超 Y 不可攻击。
- **AC 组装**：无甲 `10 + DEX`；轻甲 `基础 + DEX`；中甲 `基础 + DEX（上限 2）`；重甲定值（DEX 为负也不罚）；**盾 +2**。穿脱耗时：轻甲 1 分钟、中甲穿 5 分钟脱 1 分钟、重甲穿 10 分钟脱 5 分钟、盾 1 动作。特殊无甲式：野蛮人 `10+DEX+CON`、武僧 `10+DEX+WIS`。重甲 STR 门槛不足 → 速度 −10 尺。
- **护甲不熟练**：一切涉 STR/DEX 的检定、豁免、攻击全劣势，**且不能施法**——一只手也就腾不出姿势组件。
- **伤害** = 武器骰系 + 属性调整值（灵巧用其所择属性），伤害可为 0 不为负；**抗性减半、易伤加倍、免疫为零**（伤害类型见 §12 B）——抗/易在一切其它修正之后应用，同类多源只算一次（「抗火焰 + 抗非魔法伤害」不会叠成 ¼）。
- **临时武器**与徒手通常按 `1d4`（临时投掷 20/60）；镀银一件武器或十发弹药 100 gp（破某些「非魔法武器免疫」。
- **非致命**：近战攻击可选击倒（目标降至 0 HP 且昏迷，不死）。
- **临时 HP**：垫在真 HP 前；不叠加（取高）；休息不补。
- 治疗上限 = HP 上限。
- **环境骨架**（落点数值全可脚本）：坠落 `1d6/10 尺`（上限 20d6）；窒息 `CON 分钟（分钟数）` 后逐轮 `DC10 CON` 豁免失败计；酷热/严寒每小时 `DC10 CON`（道具护具可免）。

## 7 暴击、濒死与即时死亡

- **暴击**：攻击 nat20 → 该次攻击的**伤害骰掷两次**（一切「骰子」都翻，固定修正值不翻）。
- **即死**：单次伤害把 HP 打到 0 之后，剩余数值 ≥ HP 上限 → 当场死亡。
- **0 HP** → 昏迷 + 失能 + 倒地（手中物落在脚边），进入**濒死豁免**：
  - 每个自己的回合开始掷 **raw d20**（不做通常修正）；
  - ≥10 成功一枚，<10 失败一枚；**nat20 = 立即回 1 HP 苏醒**；**nat1 = 两枚失败**；
  - 三枚成功 = 伤势稳定（停掷，1d4 小时后自然回 1 HP）；三枚失败 = 死亡；
  - 0 HP 时再受伤 = 自动一失败；**该伤害来自暴击 = 两失败**（对昏迷/麻痹者的近战命中天然成暴击——「5 尺内近战双失败」是这个的推论）；
  - 任意治疗 ≥1 HP 即醒；**稳定或回血后成败标记双双清零**（RAW 明文）。
- **急救稳定**：动作 + `DC10 WIS(医药)` 检定成功 = 伤势稳定（免继续掷濒死，但不回血）。怪物 0 HP 默认直接死亡（规则明示的 GM 缺省，免拖戏）。
- 「稳定」状态下的昏迷可持续（1d4 小时自然醒），醒后 HP = 1。

## 8 休息与生命骰（HD）

- **生命骰**：每级 1 枚职业骰：法师/术士 `d6`；诗人/牧师/德鲁伊/武僧/盗贼/契术师 `d8`；战士/圣骑士/游侠 `d10`；野蛮人 `d12`。LV1 HP = 最大骰面 + CON；此后每级 +（掷骰 或 骰面/2 向上取整）+ CON。
- **短休**：≥1 小时轻活动（吃喝/阅读/包扎）；结束时可花费任意枚 HD，每枚掷 `骰面 + CON` 回血——掷一枚看结果再决定下一枚。次数无上限（一天多次合法）。
- **长休**：≥8 小时（其中 ≥6 小时睡眠、站哨等轻活动 ≤2 小时）；结束时 **HP 全回 + 恢复总 HD 的一半（至少 1 枚）+ 法术位/长休充能资源全回**。开始长休须 ≥1 HP（0 HP 昏迷者先要被救醒）。**作废条件**：被「≥1 小时」的剧烈活动（行走/战斗/施法等）打断 → 从头再来；短于 1 小时的中断按官方裁定只暂停计时（中断期不计入 8 小时）。长休收益 24 小时内至多一次。
- 「临时 HP」持续到耗尽或长休结束为止，长休本身不回复它。

## 9 施法与资源

- **法术位表**见 §12 F（有界大表）。戏法（0 环）不限量施放；升级环阶时戏法伤害不跟槽位走（按施法者等级档）。
- **仪式施法**：有此标法术可 +10 分钟不费法术位施放（只有准备型职业）。
- **组件**：语言 V（被缚/堵嘴不可）、姿势 S（须一只空手——持盾的手视为占用）、材料 M（无价的常备法包可代；有价的会被消耗）。双手被占用是否互相妨碍由 DM 裁定（§14）。
- **专注**：同一时刻**至多一个**专注法术。专注期间受伤 → `max(10, 伤害一半)` 的 CON 豁免维持；失能或死亡即断；再施专注法术会结束前一个（主动放弃也随时可以）。
- **法术攻击** = `d20 + 熟练 + 施法属性调整值` 打 AC；**法术豁免 DC** = `8 + 熟练 + 施法属性调整值`。
- **升环（Upcasting）**：高槽位施放低环法术，按下调档效果判定（通常加骰池、伤害/目标数档上升）。升环按法术卡逐法术有变体描述；没有变体的只费槽不增益。

## 11 创角起点（有界）

- 属性三种生成：标准阵列 `15,14,13,12,10,8` / 27 购点（8 起，15 止）/ `4d6` 取三高掷六次。
- 2014 起点三件：**种族**（`+2/+1` 或变体 `+1+1+1`、速度/体型/暗视等种族特征）、**背景**（2 项技能熟练 + 2 项工具/语言 + 1 个背景特性）、**职业**（HD、豁免熟练二、技能选数、初始装备或起始金、职业核心特征）。
- 子职业在 LV1 或 LV3 分岔。

## 12 有界大表（lore 的天然候选）

**A. 状态（15 项 + 力竭）**——每项语义封闭，可写成两行实体卡：

| 状态 | 一行语义 |
|---|---|
| 目盲 | 自身攻击与需视力的检定劣势；对它的攻击有优势；需视力的检定自动失败 |
| 受魅 | 不能攻击魅惑者；魅惑者对它的社交检定有优势；把它当友善熟人看待 |
| 耳聋 | 不能听；凡需听力的检定自动失败 |
| 惊惧 | 恐惧源在视野内时，自身攻击与检定劣势；不能主动向恐惧源移动 |
| 被擒 | 速度 0（一切速度加值失效）；对非擒抱者的攻击与敏捷豁免劣势；擒抱者失能或自身被移出其触及即解脱 |
| 失能 | 不能动作/附赠/反应；不能说话；能被动移动 |
| 隐形 | 对它的攻击有劣势、它的攻击有优势；位置仍可循声响与足迹暴露 |
| 麻痹 | 失能 + 不动不语但知觉在；STR/DEX 豁免自动失败；对它攻击有优势、5 尺内命中即成暴击 |
| 石化 | 化为石像（体重十倍、不再老化）：失能且无知觉；STR/DEX 豁免自动失败；对它攻击有优势；**对一切伤害抗性**；免疫毒与疾病（已有之毒冻结不愈） |
| 中毒 | 自身攻击与检定劣势 |
| 倒地 | 自身攻击劣势；**5 尺内**的攻击者对它有**优势**，**5 尺外**的攻击者对它**劣势**；爬行半速，起身花一半移动 |
| 受缚 | 自身攻检与敏捷豁免劣势、速度 0；攻击者对它的攻击有优势 |
| 震慑 | 失能 + 不能动、言语含混；STR/DEX 豁免自动失败；对它攻击有优势（**无自动暴击**——那是麻痹/昏迷的专利） |
| 昏迷 | 失能 + 无知觉 + 倒地（手中物落地）；STR/DEX 豁免自动失败；对它攻击有优势、5 尺内命中即成暴击 |
| 力竭（6 级轨） | ① 全属性检定劣势 ② 速度减半 ③ 攻击与豁免劣势 ④ HP 上限减半 ⑤ 速度 0 ⑥ 死亡。各级效果累积叠加；长休降 1 级（须进食进饮） |

## 13 怪物、CR 与遭遇预算（DM 侧数学）

- **怪物块解剖**（= lore/characters 数值节的结构候选）：AC、HP（骰式）、速度、六属性、豁免/技能熟练、伤害抗性易伤免疫、感官、语言、CR、动作列表。
- **CR → XP**（常用段）：CR0 `10` / ⅛ `25` / ¼ `50` / ½ `100` / 1 `200` / 2 `450` / 3 `700` / 4 `1,100` / 5 `1,800` / 6 `2,300` / 7 `2,900` / 8 `3,900` / 9 `5,000` / 10 `5,900` / 11 `7,200` / 12 `8,400` / 13 `10,000` / 14 `11,500` / 15 `13,000` / 16 `15,000` / 17 `18,000` / 20 `25,000`。

## 14 DM 裁量哲学（进提示词）

- **具体压倒通用**；规则沉默时**裁定优先**（rulings over rules），此后保持一致。
- 奖励创意描述：有趣的动作方案给优势/降 DC，不写死清单。
- **失败不停止叙事**：失败要有代价（证据丢失/情报错判/节外生枝），但不成终局。
- **不要拿检定作墙**：常识可行的方案直接让它过。
- 三支柱：战斗/社交/探索（配比无规则，餐桌自定）。
- 数字只在叙事关键处写明（伤害/HP 变化）——正文是尾代理唯一的记账来源。

## 15 时间进位

- 战斗轮 6 秒；短休 1 小时；长休 8 小时；仪式施法 +10 分钟。
- 「持续 1 轮」= 到你的下个回合开始。
- 旅行正常速 3 英里/时（≈24 英里/日）；急行 +50% 但全天被动醒觉劣势；慢速（侦查面）一半。
- 光照：正常/微光（靠暗视不失明但视力受限）/黑暗——主要影响远程与隐匿。
