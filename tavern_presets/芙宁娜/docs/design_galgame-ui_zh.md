# 芙宁娜 galgame UI · v2 设计(对话框状态机重构造)

状态:设计定案(待原型验收→照图施工) | 日期:2026-09-22 | 原型:`docs/proto_galgame-ui.html`

## 0. 现状问题(为什么要推翻)

1. **立绘截头**:`background-size:cover` + 默认 center 把人像上半身裁掉(用户原话:只露下半部分)。修法:cover + `background-position: 50% 20%`(锚头身),原型可直观对照。
2. **无滚动、无段落感**:整段回执一次性糊进对话框——galgame 的核心手感(逐段点读)完全缺位。
3. **输入框常驻**:ADV 的节奏是"读点完才有资格说话"。

## 1. 布局(自上而下)

```
┌──────────────────────────────────────────────┐
│  CG 层栈(cover·锚头身;backlog 态变暗+微缩)  │
│          (点击=下一段;backlog 态点击=收起)    │
│┌────────────────────────────────────────┐   │
││ ▼backlog(75%高,滚动,user右对齐/assistant左对齐,│
││          截止到已读段落——防剧透)        │   │
│└────────────────────────────────────────┘   │
│╔════════════════════════Pinterest═══════╗   │
│║ [芙宁娜◈名字牌]            [⌃展开钮]║   │ ← 对话框(底贴边)
│║  当前段落文本(打字机流式,28ms/字)      ║   │
│║  ▼(右下浮动·仅有余段) usage小字(底右)║   │
│╚════════════════════════════════════════╝   │
│ (输入态:名字牌变「你」,框内嵌 textarea+发送) │
└──────────────────────────────────────────────┘
```

## 2. 状态机(dialog 的唯一状态)

```
 reading(段 r 打字中)──click──▶ done/complete(打字立即补全)
     │complete 后 click
     ▼
 r+1 < N?──yes──▶ reading(段 r+1)
     │no(全部点完)
     ▼
 consumed ──click 一次──▶ input(名字牌=「你」,框内输入)──Enter/发送──▶ waiting(三点弹跳+停止小键)
     ▲                                                              │回复落盘(rev 变)
     └────────────────────────── 重新振铃(r=0,reading 段1)◀────────┘

 backlog:任意状态可开(展开钮);r 进度不因 backlog 改变;backlog 态下背景点击=先收起(不误触跳段)。
 初始(会话无回复):直接 input 态。
```

铁则:
- **点击节流**按段不按字(打字中 click=补全本段;补全后 click=下一段)——ADV 双击语义;
- ▼ 倒三角**仅"存在下一段"时**出现,"慢悠悠"(1.4s ease 往复浮动);
- 名字牌颜色随态:reading/waiting=芙宁娜(金);input=你(青)。

## 3. 段落与历史

- 分段规则:回复正文按**空行**切段;段内换行保留;进入前先剥指令注释(`<!--…-->`)。
- Backlog(展开):**完整历史**(此前所有 user/assistant 轮次)+ **当前回复的已读段**——
  **防剧透**:assistant 本轮已产出 10 段而玩家只点到第 5 段,展开也只到第 5 段;
- 对齐:assistant 行名字牌左对齐(左气泡),user 行名字牌右对齐(右气泡);
- 段落进度是**会话期 UI 态,不落盘**:换绑/刷新重置为第 1 段(重读;ADV 习惯)——防"不点完不能输入"卡死,点完 10 段通常秒级。

## 4. 输入与停止(v2 修订:停靠宿主 composer,零转发)

- 输入态 = **宿主 composer 原件停靠入位**(用户拍板"功能块与当前输入框对齐"):
  CSS 把真 `.tavern-composer` 显示并钉在对话框的输入行位置——**模型座/上下文环形/textarea/发送键/usage 线全部原生**,弹层(选模型/努力档)天然可用,Enter 原生发送;
- 红线随之干净:卡**不再编程触发**宿主 send-btn(零转发、零镜像);"只填不发"场景反而无需 textarea 镜像——draft 恒走原生;
- reading/waiting 态 composer 隐回 display:none(读点完才有资格说话);
- waiting 态的「停止」上边缘小钮 = 显示停靠态 composer 一拍并高亮其停止键(或直接由停靠态承担)——停止路径全原生,转发仅此一处且是玩家点击回调(声明:touch 级手势转发,非自动);
- usage 统计线挪**对话框外·正下方·灰色小字**(input 态也保留;输入/输出/缓存/速度 四项)。
- 模型座+上下文环形:仅 **input 态**出现,顺序为模型座(左)→环形(右),环形的右缘不越过发送键右缘(与输入行同排右对齐;reading/waiting 态随 composer 隐去)。

## 5. 流式语义(声明,非缺陷)

快照是 durable 粒度(结算后才含回复),token 级实时流不可达(转写区在 galgame 形态下隐形)。
本设计的"流式"= **段内打字机动画**(28ms/字)。waiting 三点弹跳承担"模型在生成"的可感知性。

## 6. CG 层

- 组装不变(manifest 层栈,rev 门控换场);定位修为 `cover + 50% 20%`;
- backlog 态:CG `filter: brightness(.55)` + `scale(.97)`——舞台让位给历史(标准 ADV backlog 观感);
- 图内情绪标牌若被对话框遮住属可接受(将来可把标牌烘到图上部)。
