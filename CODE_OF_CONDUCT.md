# Code of Conduct · 行为准则

## English

This project follows a short, standard code of conduct — be friendly, be respectful, be constructive. It applies to everyone participating in this repository: issues, PRs, discussions, and any other project space.

**Expected**: assume good faith; critique ideas and code, not people; keep feedback specific and actionable; be patient with newcomers and with translation gaps — this project's community works across Chinese and English.

**Unacceptable**: harassment, personal attacks, discriminatory or demeaning language of any kind, spamming, or publishing other people's private information (including API keys and workspace contents) without consent.

**Enforcement**: maintainers may edit, remove, or reject contributions and comments that violate this standard, and may ban repeat offenders. Report problems by [reporting content on GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) or by contacting a maintainer directly (privately, e.g. via the contact in [SECURITY.md](SECURITY.md) — non-security conduct reports are fine there too).

## 中文

本项目遵循简明的行为准则——友善、尊重、建设性。适用于在 issue、PR、讨论区及一切项目空间参与的每个人。

**期待**:默认善意;批评观点与代码,不针对人;反馈具体、可执行;对新人以及中英文之间的翻译缝隙保持耐心——本项目的社区同时使用中英两门语言。

**不可接受**:骚扰、人身攻击、任何形式的歧视或贬损言论、灌水,以及未经同意公开他人隐私信息(包括 API Key 与工作空间内容)。

**执行**:维护者可以编辑、移除或拒绝违反本准则的发言与贡献,并可封禁屡犯者。遇到问题请通过 [GitHub 内容举报](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)或直接私下联系维护者(渠道同 [SECURITY.md](SECURITY.md),非安全类举报亦可走该渠道)。
